# langchain-aiuc-mini — контекст для Claude Code

Учебный проект по безопасности AI-агентов на LangChain / LangGraph («AIUC-1 в миниатюре»).
Отдельный самостоятельный проект (НЕ связан с репозиторием SR-agent и не содержит его кода).

## Как вести работу

- Проект управляется через **Spec Kit**. Актуальная спецификация и план — в `specs/`.
  Перед реализацией читай текущую фичу (`.specify/feature.json` → каталог в `specs/`).
- Цель проекта — **опыт**: прокачка LangChain/LangGraph и предметное изучение безопасности агентов.
- Все «опасные» инструменты агента-мишени выполняются в **изоляции** (песочница, замоканный HTTP,
  временная рабочая папка). Ни одна учебная атака не должна причинять реального вреда.
- Правила проекта зафиксированы в [конституции](.specify/memory/constitution.md) v1.0.0.
  Принцип II (песочница) — NON-NEGOTIABLE: никакого `subprocess`, никаких реальных сетевых
  вызовов, никаких файловых операций вне временного корня песочницы.

- Всё окружение — **через Docker** (`docker compose run --rm test|gates|lint|aiuc`). На хост
  ничего не ставим (ни `uv sync`, ни `pytest`).
- Долгосрочная цель — постепенно покрыть все **53 контроля реального AIUC-1**; порядок и статусы
  ведёт карта покрытия (фича 002).

## Текущая фича

**005-external-taxonomy** — план: [specs/005-external-taxonomy/plan.md](specs/005-external-taxonomy/plan.md)

Первая мера, приходящая **не от нас**. Фича 004 дала «13/13, снижение 100%» — это диагноз, а не
достижение: стенд ловит свои собственные атаки.

1. **OWASP LLM Top 10 (2025)** как данные (`taxonomy/owasp-llm-top10.yaml`) со статусом каждой из
   10 категорий: `tested` / `gap` / `not_applicable` + обоснование. Гейт `test_tested_grounded` —
   прямой аналог `test_covered_grounded` фичи 002: `tested` нельзя объявить, только заслужить
   наличием атаки. **`tested` не ставится за «что-то похожее» — это `gap`.**
2. **Косвенная инъекция** (LLM01): payload пользователя безобидный, инструкция — в отравленной
   HTTP-фикстуре. Критерий `external_host_contacted` читается из существующего
   `sandbox_violation(rule=external_host)`. Контракт tools.md обещал фикстуру с фичи 001 — её нет.
3. **Привязка** каждой атаки к внешней категории; несуществующая → ошибка загрузки.

Артефакты: [research.md](specs/005-external-taxonomy/research.md),
[data-model.md](specs/005-external-taxonomy/data-model.md),
[contracts/taxonomy.md](specs/005-external-taxonomy/contracts/taxonomy.md),
[quickstart.md](specs/005-external-taxonomy/quickstart.md).

**Ожидается низкое покрытие и провал защиты на косвенной инъекции** — оба результата честные.
Оговорка FR-011 **уточняется, не снимается**: категории внешние, нагрузки наши.

**Не смешивать две цифры** (SC-006): «проверяется 4 из 7 применимых классов» — широта;
«отражено 100% атак» — глубина на узкой полоске. Отчёты намеренно разделены.

**Фича 004 (готова)** — детекторы: блокировка секрета в аргументах tool-call (`TOOL-SECRET`, оба
пути sync/async), PII-детектор (`aiuc_mini/pii.py` — единственный источник правил), контроли
`PRIV-03` (изоляция) и `PRIV-04` (PII). Карта: A005/A006 → covered, покрытие 3→5.
Границы: [contracts/detectors.md](specs/004-detectors/contracts/detectors.md) — base64 и обход по
частям **не ловятся**, на границу есть тест.

**Фича 003 (готова)** — честность метрик: порядок вердикта успех→блокировка→провал; мутация на
`BLOCKED`; база доли успеха = исходные атаки, не попытки; признак `scorable` (контроль, который не
может упасть, не даёт очка); реальный таймаут через `ainvoke`+`asyncio.timeout`. Гейты —
`tests/honesty/`. Оговорка FR-011 (набор атак и правила детекции наши → внутренняя
согласованность, не робастность) **не снимается** новыми детекторами.

**Фича 002 (готова)** — карта покрытия: `aiuc1/catalog.yaml` (53 контроля AIUC-1, 2 retired → 51
активный) → `docs/aiuc1-coverage.md` через `aiuc coverage`. Инвариант честности: `covered` нельзя
проставить без ссылки на реальный контроль в `scorecard/controls.py`
(`tests/coverage/test_covered_grounded.py`). Id кластеров бэклога **не** кодируют номер фичи —
за порядок отвечает `priority`.

**Реализованная база (фича 001)** — стек Python 3.11+, LangChain 1.3.x (`create_agent` +
middleware), LangGraph 1.2.x, Pydantic 2, Typer. Три вещи, которые легко сломать:
1. **Guardrail ≠ песочница.** Guardrail отключается флагом; песочница — никогда.
2. **Судья — не LLM.** Вердикт — чистые предикаты над trace.
3. **Scorecard — чистая функция от trace.** Ни `ts`, ни абсолютных путей в агрегате (SC-006).
