# Implementation Plan: Карта покрытия AIUC-1 и бэклог расширения

**Branch**: `002-aiuc-coverage-map` | **Date**: 2026-07-15 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/002-aiuc-coverage-map/spec.md`

## Summary

Аналитический deliverable, не рантайм-фича. Единый **машиночитаемый каталог** (`aiuc1/catalog.yaml`)
описывает все 53 контроля AIUC-1: id, пиллер, природа, базовый статус покрытия, флаг `partial` с
разбивкой, привязка к сущности стенда, обоснование, пункт бэклога. Из этого единственного
источника **генератор** строит человекочитаемую Markdown-карту (`docs/aiuc1-coverage.md`) и
бэклог — так исключается ручное расхождение (SC-003). **Валидатор-тест** под Docker гарантирует
инварианты: ровно 53 контроля с верными id, сумма по базовым статусам == 51 (активные), и — главное — ни
один `covered` не проставлен без ссылки на реально существующий контроль в
`scorecard/controls.py` (SC-004, проверка против кода).

Фича **не реализует** ни одного нового контроля безопасности — только каталогизирует и планирует.

## Technical Context

**Language/Version**: Python 3.11+ (тот же рантайм, что и стенд)

**Primary Dependencies**: `pyyaml` (уже в проекте), `pydantic` 2.13.x (схема каталога); генератор
и валидатор — стандартная библиотека. Новых зависимостей не вводится.

**Storage**: файлы. Источник истины — `aiuc1/catalog.yaml`. Производные —
`docs/aiuc1-coverage.md` (карта + бэклог). БД нет.

**Testing**: `pytest` в контейнере (`docker compose run --rm test`). Ключевой тест — валидатор
каталога; плюс тест «Markdown порождён из каталога и не разошёлся».

**Target Platform**: локальный, всё через Docker (предпочтение проекта: на хост ничего не ставим)

**Project Type**: single project — расширение существующего пакета `aiuc_mini`

**Performance Goals**: не применимо (статический каталог из 53 записей)

**Constraints**:
- единый источник истины: Markdown MUST порождаться из YAML, не редактироваться вручную (SC-003);
- `covered` MUST быть проверяем против кода — сверка с идентификаторами контролей в
  `scorecard/controls.py` (SC-004);
- сумма по базовым статусам == 51 (активные); `partial` — модификатор, вне агрегации по статусам (из clarify)

**Scale/Scope**: 53 контроля, 6 пиллеров, ~5–8 кластеров бэклога

src/aiuc_mini/aiuc1/

tests/coverage/
├── test_catalog_valid.py    # 53 контроля, верные id, сумма статусов == 51 (активные)
├── test_covered_grounded.py # ни один covered без ссылки на scorecard/controls.py (SC-004)
└── test_render_pure.py      # Markdown порождён из каталога, детерминирован, не разошёлся

**Structure Decision**: Single project — небольшое расширение пакета `aiuc_mini` новым
подпакетом `aiuc1/`. Каталог-данные (`aiuc1/catalog.yaml`) лежат в корне рядом с `attacks/`,
по аналогии с уже существующим набором атак: это данные, а не код. Карта в `docs/` — рядом с
существующим `docs/GUIDE.md`.

Тест `test_covered_grounded.py` выделен отдельно, потому что это исполняемый гейт честности карты
(SC-004): он связывает статус `covered` с фактическим кодом и не даёт карте разойтись с
реальностью — прямой аналог гейтов конституции из фичи 001.
